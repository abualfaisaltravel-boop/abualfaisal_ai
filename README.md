# أبو الفيصل للذكاء الاصطناعي | Abu Alfaisal AI

مستودع تطوير أدوات **أبو الفيصل للسفريات والسياحة**.

## الهدف
بناء أدوات عملية يمكن الوصول إليها من الهاتف تساعد على:
- إدارة أفكار الإعلانات والريلز.
- تنظيم السيناريوهات والمشاهد وتفاصيل الإنتاج.
- مراجعة المواد الإعلانية قبل النشر.
- تطوير واجهات وأدوات قابلة للنشر باستخدام خدمات مجانية حيث أمكن.

## آلية العمل
- **ChatGPT Plus**: تطوير المتطلبات والبرمجة والمراجعة ضمن حدود الخطة.
- **GitHub**: تخزين ملفات المشروع والتحكم في الإصدارات.
- **Render**: خيار لاستضافة الواجهات ضمن حدود خطته المجانية، بعد تجهيز التطبيق.
- **Claude Free**: يمكن الاستفادة منه بشكل مستقل إذا توفّر الوصول؛ لا يوجد ربط تلقائي مباشر بين اشتراك ChatGPT Plus وClaude Free.

## خصوصية وأمان
هذا المستودع **عام (Public)** حاليًا. يمنع حفظ مفاتيح API أو كلمات المرور أو بيانات حجوزات العملاء أو بياناتهم الشخصية فيه.

## حالة المشروع
تم إنشاء ملف التعريف الأولي، ولم يبدأ بعد تشغيل تطبيق ويب أو توليد فيديو آلي.
