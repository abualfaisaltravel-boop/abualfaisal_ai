# بوت استقبال واتساب — أبو الفيصل للسفريات والسياحة

## الحالة الحالية

**تم تجهيز كود استقبال فقط — ليس بوتًا مباشرًا بعد.** لا يستطيع هذا المستودع العام أو GitHub Pages وحده قراءة رسائل واتساب أو تشغيل خادم webhook. لن يبدأ استقبال الرسائل حتى يُنشَر الكود على خادم متوافق مع Workers ويُربط برقم جديد عبر واجهة Meta الرسمية.

الهدف: إضافة **رقم جديد مستقل** مملوك للمكتب، دون المساس بالرقم الحالي أو الأجهزة والمحادثات الموجودة.

### الوظائف المُنفّذة بالكود

- يستقبل أحداث WhatsApp Cloud API الموقّعة بتوقيع Meta ويتحقق منها عبر \`x-hub-signature-256\`.
- يقتصر على \`PHONE_NUMBER_ID\` الخاص بالرقم الجديد فقط، ويستبعد أحداث بقية أرقام الحساب.
- يتجاهل إشعارات التسليم وأي بيانات لا تحتوي على رسالة واردة.
- ينشئ طلبًا محليًا على قاعدة بيانات خاصة، ويحدّث الطلب المفتوح للعميل نفسه بدل تكراره عند كل رسالة.
- يصنّف نصوص الطلبات مبدئيًا: تذاكر، تأشيرات، عمرة، فنادق، موافقات، متابعات.
- يوزع الطلبات الجديدة بالتناوب المبدئي على زيد العودي وموسى باعباد.
- يحفظ النص المستلم دون اختراع سعر أو رحلة، ولا ينزّل المرفقات أو يطلب بيانات دفع.
- يتجنب تكرار معالجة رسالة webhook نفسها عبر معرّف الرسالة.
- لا يرد على العملاء تلقائيًا. وضع المراقبة والاستقبال فقط مقصود للمرحلة الأولى.

**غير مُنفّذ بعد**: الاتصال بقاعدة بيانات العرض الموجودة في استوديو أبو الفيصل، عرض طلبات D1 بأمان للموظفين على الموقع، تنبيه الخمس دقائق، استيعاب الصوتيات، التوقف بعد رد الموظف، جدولة الرسائل وقواعد المراسلة، وأي رسائل صادرة.

## ما يلزم لإطلاقه فعليًا

1. رقم ثانٍ تملكه الوكالة وقادر على استقبال رمز SMS أو مكالمة، ولا يُشغَّل عليه واتساب الشخصي أو واتساب الأعمال العادي في الإعداد التقليدي للـ Cloud API.
2. حساب Meta Developers وتطبيق Meta مرتبط بمؤسسة المكتب، وإضافة المنتج WhatsApp.
3. اختيار **الرقم الجديد فقط** والتحقق من ملكيته، واستلام \`PHONE_NUMBER_ID\` ومعرّف حساب واتساب الأعمال \`WABA_ID\`. لا تستخدم رقم المكتب الحالي.
4. استضافة Cloudflare Worker جديدة وقاعدة بيانات D1 خاصة ثم تطبيق \`schema.sql\` عليها.
5. ضبط الأسرار في إعدادات Worker (Secrets)، وليس في GitHub أو ضمن الكود أو محادثة الدعم:
   - \`META_APP_SECRET\`: سر تطبيق Meta.
   - \`WEBHOOK_VERIFY_TOKEN\`: كلمة تحقق تختارها للمطابقة مع Meta.
   - \`ADMIN_API_KEY\`: رمز وصول سري طويل عشوائي، 32 محرفًا فأكثر.
   - \`PHONE_NUMBER_ID\`: معرّف الرقم الجديد فقط، ليس رقم الهاتف الظاهر للعميل.
6. نشر Worker، وضبط \`https://YOUR-WORKER.workers.dev/webhook\` كـ Webhooks Callback URL في منتج WhatsApp ضمن Meta، وتفعيل الاشتراك في حدث \`messages\` وربط التطبيق بحساب WABA.
7. إجراء تجربة برسالة واردة إلى **الرقم الجديد**؛ التحقق من إنشاء الطلب في D1 قبل السماح بأي رد تلقائي.

## طريقة نشر تقنية — للمطور المسؤول

يُستخدم [Cloudflare Wrangler](https://developers.cloudflare.com/workers/wrangler/) وقاعدة [D1](https://developers.cloudflare.com/d1/). بعد الدخول إلى حساب Cloudflare:

\`\`\`bash
npx wrangler d1 create abu-alfaisal-whatsapp
# أنشئ ملف wrangler.toml حسب wrangler.example.toml،
# ثم ضع database_id الحقيقي من أمر الإنشاء في الملف.
npx wrangler d1 execute abu-alfaisal-whatsapp --file=./schema.sql --remote
npx wrangler secret put META_APP_SECRET
npx wrangler secret put WEBHOOK_VERIFY_TOKEN
npx wrangler secret put ADMIN_API_KEY
npx wrangler deploy
\`\`\`

استخدم بيئة العمل داخل المجلد \`whatsapp-bot\`. لا تضع الأسرار أو أرقام جوازات العملاء في متغيرات عامة أو إعدادات GitHub. واجهة \`GET /api/requests\` تتطلب Authorization Bearer، وهي **للخوادم المصرّح لها** وليست للاستدعاء المباشر من JavaScript المنشور في موقع GitHub Pages، لأن وضع المفتاح في الموقع العام يعرّض بيانات العملاء للخطر.

**ملاحظة تشغيلية:** يتطلب الربط النهائي تسجيل الرقم والاشتراك في webhook لدى Meta. لا تنشر رقمًا حقيقيًا إلا بعد التأكد من الموافقات والسياسات والكلفة. اختيار رقم جديد منفصل يحافظ على أرقام المكتب الأصلية دون تعديلها.

## واجهة الخدمة

- \`GET /health\`: حالة الخدمة العامة.
- \`GET /webhook\`: تحقق Meta من رمز webhook.
- \`POST /webhook\`: استقبال webhook الموقّع من Meta.
- \`GET /api/requests\`: قائمة الطلبات (Bearer سرّي).
- \`PATCH /api/requests/:id\`: تغيير الحالة أو الموظف (Bearer سرّي).

## ما المرحلة التالية؟

ربط استوديو أبو الفيصل بلوحة مشتركة بخلفية آمنة وتسجيل دخول خاص بالموظفين، بدل LocalStorage وحده. عندها تُعرض الطلبات الواردة من هذا الرقم الجديد تلقائيًا في نفس لوحة التشغيل الحالية، دون بناء موقع بديل.
